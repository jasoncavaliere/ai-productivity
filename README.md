# AI Productivity

Toolkit and templates for AI-assisted product and engineering workflows.

## What's in this repo

- `.codex/`: Codex configuration, skills, and prompt assets
- `.github/`: agent and prompt definitions for Speckit workflows
- `.specify/`: specification scripts, templates, and project memory
- `.vscode/`: editor settings

## Getting started

1. Clone this repository.
2. Open it in your editor/terminal.
3. Use the prompts, skills, and templates under `.codex/`, `.github/`, and `.specify/` to run your workflow.

## Notes

- This repository is configuration-first and may not contain a traditional app entry point.
- Add project-specific setup instructions here as the repository evolves.
